# Contributor Code of Conduct

Our project follows a code of conduct to foster a welcoming community for everyone. By participating, you agree to:

- Be respectful and considerate in all communications.
- Refrain from discriminatory or harassing behavior.
- Accept constructive feedback and respond professionally.

If you witness or experience unacceptable behavior, please contact the repository maintainers with relevant information so we can address it.

This is a short version; maintainers may adopt a more detailed policy later.
