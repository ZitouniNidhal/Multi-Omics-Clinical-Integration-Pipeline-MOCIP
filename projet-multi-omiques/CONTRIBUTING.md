# Contributing

Thanks for your interest in contributing to the Multi-Omics Clinical Integration Pipeline.
Please follow these simple steps so we can review and merge your changes quickly:

- Fork the repository and create a feature branch from `main`.
- Open a clear, focused pull request with a descriptive title and summary.
- Include tests or a demonstration script for non-trivial changes.
- Keep changes small and focused; prefer many small PRs over a single large one.
- Run the test suite locally before submitting: `python -m unittest discover -s . -p "test_*.py"`.

Coding standards:
- Follow existing project style (PEP8 for Python).
- Add docstrings for public functions and classes.

When your PR is ready:
- Add a brief description of the change and the motivation.
- Link any related issues or external references.

We appreciate your contributions—thank you!
